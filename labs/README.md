# Лабораторные работы: консольный чат на Node.js

Пятнадцать лабораторных по порядку разбирают все технологии и приёмы,
из которых состоит чат из этого репозитория. После них у вас будет
свой чат, собранный с нуля по [техническому заданию](15-chat/chat-tz.md),
и понимание каждой его строки.

## Как устроена каждая лабораторная

- **Теория** — коротко и с примерами кода.
- **Упражнения** — маленькие самостоятельные программы в отдельной папке-песочнице.
  Решения лежат в папке `solution/` каждой лабораторной. Сначала решите сами.
- **Шаг проекта** — кусок вашего собственного чата. Проект `chat/`
  создаётся в лабораторной 1 в отдельной папке и растёт от лабораторной
  к лабораторной. Удобно делать по коммиту на каждую.
- **Контрольные вопросы** — проверьте, что поняли, а не только сделали.
- **Где это в эталонном проекте** — ссылки на код этого репозитория
  и на теги `step-N` в его истории.

## Что нужно

- Node.js 22 или новее (`node --version`).
- Терминал: bash, zsh или PowerShell. Команды в лабораторных написаны
  для bash. Если в PowerShell команда отличается, это указано рядом.
- Редактор кода и git.

## Как запускать решения

Решения пользуются модулями эталонного проекта и пакетами из его
`node_modules`, поэтому сначала установите зависимости в корне репозитория:

```bash
npm install
```

Обычные решения запускаются через `node`, тесты — через `node --test`:

```bash
node labs/04-async/solution/parallel.js
node --test "labs/07-testing/solution/*.test.js"
```

`npm test` эталонного проекта решения лабораторных не запускает.
`npm run lint` и `npm run format:check` проверяют и их.

## Для преподавателя

- Время указано примерное, для студента, который делает упражнения сам.
  Вся программа занимает 35–45 часов.
- Самая важная проверка архитектуры — в лабораторных 13 и 15: тесты
  эталонного проекта должны пройти на коде студента без правок.
- Интерактивные упражнения (ввод в терминале во время входящих сообщений,
  Ctrl+C) нельзя проверить автотестами. Их стоит посмотреть вживую.
